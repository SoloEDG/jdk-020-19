
## 正式交接班

顶栏「交班」进入交班面板（右下角「重置」仅用于演示重置现场，会清空一切）。

- **交班时刻同时是两条边界**：交班瞬间结算上一班，并原样成为下一班的初始现场。
  未离港飞机、进行中保障、在途车辆与机位占用都会随班次移交，不会瞬移回库。
- **延误归属独立**：航班记录 `delayCarried` 与 `delayLedger`，已发生的延误带入下一班但不重复扣分；
  接班后新增的延误只记在下一班账上。续班作业按剩余量继续（车辆位置、任务进度、剩余秒数）。
- **交班前后对比**：面板并列「立即交班」与「值守至计划交班」的可结算分、本班新接进港数与风险等级，
  提前交班能少接航班但少结算，值守更久可多结算但要多接进港。
- **交接前风险检查**：延误、缺车、客舱清洁依赖冲突、无机位可分配等会列出；阻断级风险需逐项勾选「已处理」，
  并勾选核对清单后才能确认交班。
- **接班计划可调整**：新进港航班按机位可用性自动排班，可顺延（±60s）或改派机位；
  与当前占用冲突时只调整新计划，现场不被丢弃或挪动。
- **只读与幂等**：确认后上一班转为只读归档；重复确认或重新打开交接结果只会返回同一后续班次，
  不会生成第二个接班班次。交接记录中的未完任务清单在两边都能核对同一笔任务（按 `taskId` 对齐）。
- **存档**：保存后再读取已交班班次会以只读方式打开归档现场。
